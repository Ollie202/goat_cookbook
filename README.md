# goat_cookbook

This is where I'll be dropping reusable stuff I learn.

## Skills

- [`goated_research.md`](./goated_research.md) — the pre-build research system: verify the hackathon, sponsor intent, winners, saturation, dependencies, buildability, and demoability before choosing what to build.
- [`goated_foundation.md`](./goated_foundation.md) — the project operating system: make the repository carry current truth, milestones, issues, evidence, decisions, and execution context so agents can build coherently across sessions.
- [`goated_benchmark.md`](./goated_benchmark.md) — the product pressure-test: compare a working build against rubric fit, evidence, differentiation, integration depth, resilience, measurable advantage, and demo quality without blindly rewriting or bloating it.

A useful default flow is:

```text
goated_research → choose the strongest build direction
goated_foundation → structure and execute it
goated_benchmark → pressure-test and improve the working product
```
